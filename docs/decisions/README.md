# Architecture Decision Records (ADRs)

Decisions 1–8 are recorded in `README.md` → Key design decisions; decisions 9–11 in `docs/decisions-9-11/`.
Any later significant decision — and any ERD change after G1 — gets a file here: `NNN-short-title.md`.

```markdown
# NNN — Title
Date · Author · Status (proposed / accepted / superseded by NNN)
## Context
## Decision
## Alternatives rejected (and why)
## Consequences (code, schema, tasks, docs to update)
```
