# HoReCa B2B Marketplace — diagrams v4 (24.11.2026)

The complete, current set of diagrams for the system as decided in decisions 1–11.
**Source of truth:** `horeca-decisions-9-11` (Drizzle schema, rls.sql, permission-matrix.md, money-rules.md) and the
planning documents of Member A (CLAUDE.md, DESIGN.md, TASKS.md). Every picture here is generated from those sources:
the ERD from the Drizzle snapshot, the matrix from permission-matrix.md, the wireframe numbers from the money rules
(asserted in code). Diagrams v1–v3 are obsolete — they describe an earlier design (own users/sessions, REST API,
Postgres search, ledger on delivery, public catalogue).

Also in this folder (Mermaid sources + PNG): `architecture` (system overview incl. the public proxy, Tailscale and the media
volume), `cicd` (pipeline), `deployment` (server layout: friend's public proxy → Tailscale → our Nginx, GitHub deploy via
the Tailscale GitHub Action, media volumes, backups). The former `erd-identity` is superseded by the identity part of `01-erd-complete` (REVIEW-FINDINGS F8).
The decision diagrams that were inside `decisions-9-11/diagrams/` are the same as 08–12 here and were removed there,
so there is one copy of each diagram.

**Numbers in the wireframes agree with each other:** Hotel Main's order 2.403,06 € (checkout) = its sub-order
ORD-2026-000123-1 (1.590,00 € net, commission 127,20 €) on the supplier dashboard = the first unpaid order on the admin
screen; supplier balances on W3 and W4 are the same ledger sums (A: 7.022,39 €; total owed 13.116,16 €; commission
earned 878,85 €).

`sources/` contains the generators (`erd_v4.py`, `wireframes_v4.py`, `matrix_v4.py`, `sitemap.dot`) and the HTML of the
wireframes — run them against the decisions zip to regenerate everything.
